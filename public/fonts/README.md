# Self-hosted fonts

Rubik Latin variable font, 300–900, downloaded from Google Fonts through the Impeccable font helper. Noto Sans Arabic regular and bold full-script fonts downloaded from the official Google Fonts CSS/CDN. Both use the SIL Open Font License; accompanying notices are included here.

The full Arabic files intentionally cover Arabic shaping and Latin fallback. CSS uses Rubik for English and Noto Sans Arabic first on RTL pages. No runtime font request leaves the app.
