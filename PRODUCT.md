# Yalla Break

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Employees in Jordan playing simple games together during their workday break, using phones and PCs. Arabic and English are equally supported.

## Product Purpose
Help colleagues choose a game, organize players, and enjoy a shared break with minimal setup.

## Capabilities and Constraints
React and Vite application with Redux state, React Router, Bootstrap, and i18next. Preserve all routes, game rules, roster formats, scoring, saved sessions, API contracts, permissions, and Firebase word-bank/history behavior. New PassWord and Pictionary games are 2v2 with two named players on each team and a separate host. Teams alternate and teammates exchange roles after both teams have played. Older saved formats remain resumable. Mafia is a separate multiplayer group role game with no configured upper player limit. ListWords and CatchPhrase remain coming soon in the library; preserve their existing routes. Light and dark appearances are supported through a persistent switch, with the system preference used before an explicit choice.

## Brand Commitments
The user authorizes a complete visual redesign. No existing color, logo, or typography is binding. Retain the product name and factual content unless a change is necessary for clarity. No new commercial claims.

## Accessibility & Inclusion
Responsive phone and desktop layouts, Arabic RTL and English LTR, keyboard operation, visible focus, readable contrast, reduced motion, and understandable loading, empty, error, and success states.

## Evidence on Hand
README.md, existing game implementations, English and Arabic translation dictionaries, existing SVG game artwork, and roster/session regression tests.
